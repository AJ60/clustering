One-Shot Implementation Spec: 1-Hop Star GGUF Cluster on Stock llama.cpp v1.0.0

Designed specifically so a lightweight coding model can build the entire project in one shot without hallucinating C++ internals. Instead of modifying llama.cpp v1.0.0 or compiling external C++ solvers, this plan wraps stock llama-server and rpc-server -c (RPC v9) inside a flat 5-file Python/Kotlin orchestrator over a 1-Hop Hub-and-Spoke Star Topology—the shortest possible route to the Master node.

1-Hop
Direct Star Topology to Master via USB RNDIS (<0.5 ms) or Master Wi-Fi Hotspot (~1.2 ms), cutting router hops in half and isolating packet loss per spoke.
1. Zero C++ Engine Edits (KISS Rule)

Never touch ggml C++ source code. Compile stock llama.cpp v1.0.0 (`llama-server` + `rpc-server`) and drive everything via CLI flags from a 300-line Python orchestrator.

2. 1-Hop Star Route + Local Cache

Every worker connects directly to the Master in 1 hop. Running rpc-server -c caches tensor weights on worker flash storage so packet drops never re-send gigabytes of weights.

3. Greedy Math (No External MILP Libs)

Replaces complex C++ MILP libraries with a 25-line Python greedy allocator that computes --tensor-split, -ngl, -ot MoE regexes, and 50% Android RAM caps.

3. Fastest 1-Hop Network Topology & Packet-Loss Protection

As shown in llama.cpp issue #22850 and empirical RPC tests, round-trip latency and Wi-Fi packet loss—not raw bandwidth—stall distributed token generation. In a home Wi-Fi network, a ring topology (`Phone 1 -> Phone 2 -> Master`) forces every packet to traverse the Wi-Fi router twice per hop.

Instead, our engine enforces a **1-Hop Hub-and-Spoke Star Topology** with automatic interface ranking: (1) USB RNDIS Tethering (`192.168.42.x`, `<0.5 ms` RTT, 0% packet loss), (2) **Master 5 GHz Wi-Fi Hotspot** (`192.168.137.x` on Windows / `10.42.0.x` on Linux, `~1.2 ms` direct 1-hop RF link bypassing the home router), and (3) **Home 5 GHz LAN** (`192.168.1.x`).

# Exact Socket Hardening & Packet-Loss Probe (Copy into node_agent.py & master_controller.py)
import socket, struct, time, zlib

def harden_socket(sock: socket.socket) -> None:
    sock.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)   # Disable Nagle 40ms buffering
    sock.setsockopt(socket.SOL_SOCKET, socket.SO_KEEPALIVE, 1)   # Detect dead peers fast
    sock.setsockopt(socket.SOL_SOCKET, socket.SO_SNDBUF, 4194304)
    sock.setsockopt(socket.SOL_SOCKET, socket.SO_RCVBUF, 4194304)
    if hasattr(socket, "TCP_QUICKACK"):
        sock.setsockopt(socket.IPPROTO_TCP, socket.TCP_QUICKACK, 1)
    if hasattr(socket, "TCP_USER_TIMEOUT"):
        sock.setsockopt(socket.IPPROTO_TCP, socket.TCP_USER_TIMEOUT, 5000) # 5s max stall

# Control Frame Format: [MAGIC 4B][SEQ 4B][LEN 4B][CRC32 4B][JSON PAYLOAD]
def send_verified_frame(sock: socket.socket, payload_dict: dict, retries: int = 3) -> bool:
    raw = json.dumps(payload_dict).encode("utf-8")
    crc = zlib.crc32(raw) & 0xFFFFFFFF
    for attempt in range(1, retries + 1):
        try:
            hdr = struct.pack("!4sIII", b"GGUF", attempt, len(raw), crc)
            sock.sendall(hdr + raw)
            ack = sock.recv(4)
            if ack == b"ACK!":
                return True
        except OSError:
            time.sleep(0.05 * attempt)  # Fast 50ms/100ms/150ms retry on transient Wi-Fi drop
    return False

# 1. Standardized Structured Logger (MUST be called at every state transition)
def log_event(level: str, node_id: str, stage: str, code: str, msg: str, **kv) -> None:
    ts = time.strftime("%Y-%m-%dT%H:%M:%S%z")
    pairs = " ".join(f"{k}={v}" for k, v in kv.items())
    line = f"[{ts}] [{level}] [{node_id}] [{stage}] [{code}] {msg} | {pairs}"
    print(line, flush=True)
    with open("logs/cluster.log", "a", encoding="utf-8") as f:
        f.write(line + "\n")

# 3. 25-Line Greedy Layer & MoE Allocator (Replaces complex MILP libraries)
def compute_cluster_plan(nodes: list[dict], gguf_meta: dict) -> dict:
    usable = [
        n for n in nodes
        if n["pkt_loss_pct"] <= 2.0 and n["rtt_ms"] <= 25.0 and n["thermal_headroom"] < 0.90
    ]
    for n in usable:
        # Score combines memory bandwidth, compute FLOPS, and 1-hop link latency penalty
        n["score"] = (n["mem_bw_gbps"] * 0.7 + n["compute_tflops"] * 10.0) / (1.0 + n["rtt_ms"] * 0.1)
    usable.sort(key=lambda x: (x["is_master"], x["score"]), reverse=True)

    needed_mb = int(gguf_meta["file_size_mb"] * 1.15)  # Weights + 15% FP8/Q8_0 KV cache reserve
    active, accum_mb = [], 0
    for n in usable:
        if accum_mb < needed_mb or n["is_master"]:
            alloc_mb = min(n["safe_cap_mb"] + n["vram_free_mb"], max(512, needed_mb - accum_mb))
            n["alloc_mb"] = alloc_mb
            active.append(n)
            accum_mb += alloc_mb
        else:
            log_event("INFO", n["node_id"], "SCHEDULER", "PRUNE_WEAK_NODE",
                      "Pruned slower node because faster nodes fit model", score=round(n["score"], 2))

    # Compute --tensor-split weights proportional to each active node's score & safe memory
    split_weights = [round(n["alloc_mb"] * (n["score"] / active[0]["score"]), 1) for n in active]
    rpc_endpoints = [f"{n['ip']}:{n['rpc_port']}" for n in active if not n["is_master"]]
    extra_flags = ["--jinja", "-ctk", "q8_0", "-ctv", "q8_0", "--flash-attn"]
    if gguf_meta.get("is_moe", False):
        extra_flags += ["-ot", ".ffn_.*_exps.=CPU"]  # Offload MoE experts to host RAM cache
    return {"active_nodes": active, "rpc_arg": ",".join(rpc_endpoints),
            "tensor_split": ",".join(map(str, split_weights)), "flags": extra_flags,
            "mmap_stream": accum_mb < needed_mb}
